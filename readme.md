# 🌪️ AeroFlow // Aerodynamic Wind Tunnel & Smoke Flow Sandbox

An interactive computational fluid aerodynamics simulation visualizing laminar streamlines, turbulent boundary layer separation, and von Kármán vortex streets around custom obstacles on HTML5 Canvas.

## 🌐 Live Demo
Test the wind tunnel: [https://rohitmaity10.github.io/wind-tunnel/](https://rohitmaity10.github.io/wind-tunnel/)

## Technical Highlights
- **Aerodynamic Potential Flow & Circulation:** Models Kutta-Joukowsky airfoil circulation, dipole boundary deflection, and Reynolds-dependent vortex shedding behind blunt bodies.
- **Neon Smoke Streamers:** Thousands of multi-point velocity tracer particles continuously calculating pressure gradients ($C_p$) and velocity vectors.
- **Dynamic Angle of Attack (AoA):** Rotate airfoils interactively to observe aerodynamic stall conditions and trailing-edge flow detachment.
- **Interactive Obstacle Sculptor:** Drag predefined aerodynamic profiles (NACA Airfoil, Cylinder, Sports Car, Flat Plate) or freely draw arbitrary solid geometry with cursor strokes.
